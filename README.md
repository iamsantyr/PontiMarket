# PontiMarket

**PontiMarket** is a mobile application developed in Swift using Xcode, designed to facilitate the buying and selling of products within the university community. It serves as a marketplace focused on student entrepreneurs who wish to offer their products in an organized, secure, and accessible way.

---

## Key Features

- Secure authentication for university users
- Product browsing by categories
- Product listings created by student entrepreneurs
- Direct contact between buyers and sellers
- Multilingual support (Spanish and English)
